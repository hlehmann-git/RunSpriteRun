Making the RunSpriteRun Setup.exe on your own PC

This turns the RunSpriteRun folder into a single installer file (RunSpriteRun_Setup_v2.0.1.exe) that you can copy to a USB stick and install on any 64-bit Windows 10 or 11 PC. The PC that runs the installer does not need Python or anything else.

You do Parts 1 to 4 once. Part 5 is the build itself and is repeated for every new version.

Part 1: Choose a build folder that is NOT in OneDrive

Use C:\Dev. A build creates thousands of small files, and OneDrive trying to sync them can slow or break the build.

Part 2: Install Inno Setup (once)

1. Go to jrsoftware.org, then Downloads, and download the Inno Setup 6 installer (innosetup-6.x.x.exe). Do not use Inno Setup 7.
2. Run it, say Yes if Windows asks to allow changes, and click Next through every screen, keeping the defaults. Click Install, then Finish.
3. Check that C:\Program Files (x86)\Inno Setup 6\ISCC.exe exists. Close the Inno Setup window if it opens.

What has happened: Inno Setup is the free program that wraps RunSpriteRun into an installer. The build script finds it by itself.

Part 3: Unzip the app

1. Right-click RunSpriteRun_v2.0.1.zip and choose Extract All.
2. Extract it into C:\Dev. You should end up with C:\Dev\RunSpriteRun\ with main.py and build_installer.bat directly inside it.

Part 4: Set up Python for the project (once)

1. Open the C:\Dev\RunSpriteRun folder in File Explorer.
2. Click the address bar, type cmd and press Enter. A terminal opens in that folder.
3. Check Python is found by typing python --version. It should say 3.12.something. If it says "python is not recognized", see "Install Python" in readme_install_new.txt.
4. Type python -m venv .venv and press Enter.
5. Type .venv\Scripts\activate and press Enter. You will see (.venv) at the start of the line.
6. Type pip install -r requirements.txt pyinstaller and press Enter. This takes a few minutes.
7. Close the terminal.

What has happened: the project folder now has its own private set of libraries (PySide6, Pillow and PyInstaller) in a .venv folder. It does not affect anything else on your PC.

Part 5: Build the installer (every time)

1. Open C:\Dev\RunSpriteRun in File Explorer.
2. Double-click build_installer.bat. A black window shows six steps and takes about 5 minutes. The packaging step (4 of 6) is the slow one and prints a lot of text. That is normal.
3. When it says Done, the folder dist_installer opens. Inside is RunSpriteRun_Setup_v2.0.1.exe.
4. If the window says the build stopped because of a problem, take a screenshot of the whole window and send it to Claude. The window stays open until you press a key.

What has happened: the script packaged the program into the dist folder and wrapped it into the Setup.exe. It also created a build folder. Both can be deleted at any time.

Part 6: Try the installer

1. Double-click RunSpriteRun_Setup_v2.0.1.exe, or copy it to a USB stick and run it on another PC.
2. Windows may show "Windows protected your PC" because the installer is not signed. Click More info, then Run anyway.
3. Choose the install folder (the suggested one, under your user folder, is fine), tick the shortcuts you want, and click Install.
4. RunSpriteRun starts when it finishes.

What has happened: the program is installed in its own RunSpriteRun folder. Projects, Exports and Blank sprite sheets are saved inside that folder. The Start Menu shortcut "RunSpriteRun files" opens it. Uninstalling (Windows Settings, Installed apps) removes the program but leaves your projects.

Part 7: A new version

Open src\version.py in Notepad, raise the number by 0.0.1 (2.0.1 becomes 2.0.2), save, and repeat Part 5. The new Setup.exe has the new number in its name.

If something goes wrong

- "The .venv folder was not found": Part 4 was not done in this folder.
- "Inno Setup 6 was not found": redo Part 2, and check that C:\Program Files (x86)\Inno Setup 6\ISCC.exe exists.
- Antivirus blocks or removes files while building: pause it for the build, or exclude C:\Dev\RunSpriteRun.
- Any other error: screenshot the whole window and send it to Claude.
