RunSpriteRun examples
=====================

The Projects folder has one folder per system, and inside it one folder per example:

    Projects\<System>\<Project name>\<Project name>.rsr

To try one: start RunSpriteRun, choose File > Open, and open the .rsr file in the folder for your system.

Some systems have more than one example (for example "Gods" and "MGS3", the Metal Gear Solid 3 sprites) to show how the same
sprite looks with each system's palette.

Each example folder also holds the sprite sheet it was made from (<Project name>_Source.png), the frame
pictures (Sprites), and the sprite sheets (Sprite_Sheet and Frame_Sprite_Sheets).

Note: Commodore 64 and Apple II (Double Hi-Res) have fixed colours, so their palette cannot be edited.
